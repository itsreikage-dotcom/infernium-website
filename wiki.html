Learn the server

Wiki

Useful commands and beginner information for Infernium SMP.

Getting started

  • Read the rules.
  • Use /spawn to return to spawn.
  • Use /rtp to find a random location.
  • Set a safe home before exploring.

Homes

  • /sethome [name] — save a home.
  • /home [name] — teleport home.
  • /delhome [name] — remove a home.
  • /homes — list homes.

Teleportation

  • /tpa [player] — request teleport.
  • /tpahere [player] — request them to you.
  • /tpaccept — accept.
  • /tpdeny — deny.

Teams

  • Use /team help to view team commands.
  • Create or join a team with trusted players.
  • Team owners should carefully manage permissions.
  • Use team chat for private coordination.

Useful commands

  • /warp — view public warps.
  • /msg [player] — private message.
  • /reply — reply quickly.
  • /links — view server links, when enabled.

Support and safety

  • Report bugs privately on Discord.
  • Take screenshots before reporting griefing.
  • Never share passwords or personal details.
  • Ask staff when unsure about a rule.

Server information

  • IP: play.infernium.org
  • Version: 1.21.11
  • Capacity: up to 150 players
  • Discord: Join here

Ranks

  • Ranks provide quality-of-life and cosmetic benefits.
  • Benefits stack through the rank hierarchy.
  • The official Tebex store is available now.
  • View the current rank benefits on the Store page.

Performance

  • Avoid oversized redstone clocks.
  • Do not build intentional lag machines.
  • Keep farms reasonable and efficient.
  • Report unusual lag with location details.
