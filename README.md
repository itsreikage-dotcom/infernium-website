# Infernium Network Website

Website static realizat în HTML, CSS și JavaScript.

## Publicare

Încarcă toate fișierele și folderele din acest director în rădăcina hostingului sau în repository-ul GitHub Pages. Fișierul principal este `index.html`.

## Structură

- `index.html` — pagina principală
- `store.html` — rankuri, crates și money
- `staff.html` — echipa serverului
- `rules.html` — regulament
- `vote.html` — votare
- `play.html` — conectare pe server
- `contact.html` — rețele sociale și contact
- `css/style.css` — design
- `js/script.js` — meniu, copiere IP, animații și status
- `images/` — logo, fundal, rankuri și skinuri
