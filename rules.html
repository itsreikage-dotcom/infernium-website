Regulament

Regulile se aplică pe lobby, survival și pe toate modurile viitoare ale networkului.

Respect și comportament

  1. Respectă jucătorii și membrii staff.
  2. Sunt interzise insultele grave, amenințările și discriminarea.
  3. Nu impersona alți jucători sau membri staff.
  4. Nu publica informații personale fără acord.

Chat și reclamă

  1. Fără spam, flood sau folosirea excesivă a literelor mari.
  2. Reclama altor servere este interzisă.
  3. Folosește canalele potrivite pentru suport și reclamații.
  4. Conținutul nepotrivit este interzis.

Gameplay

  1. Hack-urile, X-Ray, macro-urile și avantajele incorecte sunt interzise.
  2. Nu exploata bug-uri sau metode de duplicare.
  3. Nu construi lag machine-uri și nu afecta intenționat performanța.
  4. Nu evita sancțiunile folosind conturi alternative.

Survival și PvP

  1. Respectă protecțiile și proprietățile altor jucători.
  2. Combat logging-ul și abuzarea zonelor safe sunt interzise.
  3. Scam-ul prin impersonarea staffului este interzis.
  4. Echipele sunt responsabile pentru membrii acceptați.

Bug-uri și rapoarte

  1. Raportează bug-urile în privat pe Discord.
  2. Trimite dovezi clare când raportezi un jucător.
  3. Nu acuza public fără dovezi.
  4. Abuzarea unui bug înainte de raportare poate fi sancționată.

Sancțiuni

  1. Stafful poate aplica avertisment, mute, kick sau ban.
  2. Sancțiunea depinde de gravitate și antecedente.
  3. Contestațiile se fac respectuos pe Discord.
  4. Decizia conducerii este finală.
